One deterministic program. It prints a single safety warning that should come on every human being.

## Run it

```sh
mkdir -p out
MAKEFUN_BOT_DIR="$PWD" MAKEFUN_OUTPUT_DIR=./out TZ=UTC PYTHONHASHSEED=0 LANG=C.UTF-8 node main.ts
```

`node main.ts` writes UTF-8 text to `$MAKEFUN_OUTPUT_DIR/entry.txt` and exits 0.
